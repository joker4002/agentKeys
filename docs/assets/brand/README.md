# AgentKeys brand assets

This folder contains the project logo set generated from the supplied AgentKeys mark.

## Files

- `agentkeys-logo-source.png` - original source image.
- `agentkeys-logo-1024.png` - transparent logo, 1024px square.
- `agentkeys-logo-512.png` - transparent logo, 512px square.
- `agentkeys-logo-256.png` - transparent logo, 256px square.
- `favicon.ico` - multi-size browser favicon.
- `favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png` - transparent favicon PNGs.
- `apple-touch-icon.png` - 180px touch icon on a white background.
- `android-chrome-192x192.png`, `android-chrome-512x512.png` - web app icons on a white background.
- `site.webmanifest` - minimal web manifest that references the generated app icons.

For HTML pages, use:

```html
<link rel="icon" href="docs/assets/brand/favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="docs/assets/brand/favicon-32x32.png">
<link rel="apple-touch-icon" href="docs/assets/brand/apple-touch-icon.png">
<link rel="manifest" href="docs/assets/brand/site.webmanifest">
```
